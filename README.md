# 日前实验室 · DayAhead Lab

**先公开预测，再公开打分。** Forecast first. Score in public.

欧洲电力市场日前电价预测与储能收益基准。每天在日前市场关门（柏林时间 12:00）之前发布次日
24 小时的电价预测和储能调度计划，第二天市场出清后自动打分，逐日记录公开在
**https://dayaheadlab.github.io**，包括错得离谱的日子。关门后才发出的预测会被标记并排除在统计之外。

A public, verifiable track record: day-ahead price forecasts for the German DE-LU bidding zone
are published before the 12:00 CET gate closure and scored automatically after clearing.
Late forecasts are flagged and excluded from the statistics.
